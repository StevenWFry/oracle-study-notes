# Course Overview — Prepare for Oracle Database Administration 1 Certification

Welcome to the certification prep course for **1Z0-082: Oracle Database Administration I** — the exam that stands between you and the letters "OCA" on your résumé. This course assumes you've done some database administration work and now need to organize all that experience into something Oracle can test you on. Think of it less as learning from scratch and more as converting your hard-earned chaos into structured knowledge.

## Prerequisites

- Familiarity with Oracle Database architecture (CDB, PDB, SGA, background processes)
- Hands-on experience with SQL*Plus and basic DBA tasks
- Completion of, or equivalent knowledge from, the Oracle Database 19c: Administration Workshop

---

## Key Takeaways

- Know the architecture cold — it's the foundation for every other topic
- Understand *why* things work, not just *how* to type the command
- The exam will test edge cases; these notes will call them out
